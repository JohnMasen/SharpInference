# SharpInference GGUF state files

`GgufStateFile.Write(stream, new GgufState(schemaName, tensors))` writes a GGUF v3 state file from the stream's current position. It requires a writable, seekable stream and does not truncate it: any existing bytes before the start position or after the written file remain in place. `GgufStateFile.Read(stream)` requires a readable, seekable stream and reads from its current position to the end of the stream, rejecting any extra trailing bytes. To read a file written into the middle of a longer stream, use a bounded stream containing only that file. The caller retains ownership of either stream; both remain open.

State-only files contain `general.architecture = "sharpinference"` and `sharpinference.state_schema.name = schemaName` as string metadata. The architecture identifies this generic state archive format, not an RWKV model architecture; callers may supply any schema name. Tensor data starts at the default 32-byte GGUF alignment; tensor offsets are relative to that start. Only unquantized 8/16/32/64-bit integer or 16/32/64-bit floating-point GGML types are accepted. No model identity or checksum is stored. Readers validate exact tensor length, shape, type, ordering, padding, and complete file length; application-level schema/tensor compatibility remains the caller's responsibility.
